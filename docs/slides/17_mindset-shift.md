## The Mindset Shift: Reconstructing Product Judgment

A useful commit creates a checkpoint around a meaningful change. **The reasoning travels with the change**, creating a trail of product logic.

&nbsp;

| Step | What it is | The GitHub mechanism |
|---|---|---|
| **What we knew** | The baseline | The main branch |
| **What changed** | New evidence | Customer interviews, market data |
| **What we considered** | Parallel exploration | Branches exploring alternatives |
| **What we decided** | The accepted direction | The pull request review |
| **Why** | The rationale | The commit message preserving it |

&nbsp;

> **Commits create a history of product judgment, not just a timestamp of an edit.**
