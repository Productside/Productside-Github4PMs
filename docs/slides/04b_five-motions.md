## The 5 Motions

Every workflow in this playbook serves one of five motions.

&nbsp;

| Motion | What it means |
|---|---|
| **Context** | Create one versioned home for strategy, research, decisions, and set the context your product team and AI tools need |
| **Communications** | Create a collaborative space where ideas can be challenged, refined, and documented before they become expensive commitments |
| **Confidence** | Keep assumptions, experiments, findings, and evidence connected so each discovery effort informs the next |
| **Constitution** | Define product guardrails and non-negotiables that GitHub can help enforce without making you the process cop |
| **Community** | Build a structured front door for ideas, requests, and contributions, with a visible record of what happened next |

&nbsp;

**Constitution** is different from the other four. It is not a step you do once. It is the thread that makes the other four safe: `CONSTITUTION.md` ships with the repo, the Content Guard action fires on every pull request, and AI reads the guardrails before it acts.
