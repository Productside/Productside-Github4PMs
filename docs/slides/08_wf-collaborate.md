## Workflow 3 · Run a skill & use what the team built

&nbsp;

**The Situation:**
You've cloned the library and installed the skills. Now you need a battle card for a competitor who showed up in two lost deals. The skill exists. Run it.

**The PM Gain:**
Instead of starting from scratch, you run a skill the team already built and validated. The output comes back cited, labeled by confidence (Fact / Inference / Assumption), and it tells you the claims you must not make. That section is the one to read first.

&nbsp;

> **The AI Prompt**
>
> ```
> Use the battle card builder skill. My product is [your product].
> The competitor is [competitor name]. We've lost two deals to them
> in the mid-market segment. Build the card from public evidence.
> ```
>
> ---
>
> **The Invisible Machinery**
>
> The skill reads `prompts/battle-card-builder-prompt.md`, asks at most 3 setup questions, sweeps public sources, and produces a field-action card a rep can open mid-deal.

&nbsp;

**What collaboration looks like here:**
- Kenny runs a skill someone else authored
- The skill's guardrails (evidence labeling, the do-not-invent list) travel with it
- The output is cited and traceable, not a hallucinated summary
- If Kenny spots a gap in the skill, that becomes the next workflow
